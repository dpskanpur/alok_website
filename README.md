# Alok's Minimalist & Nerd-Designer Portfolio

A minimalist, content-focused, two-color (Stark Black + Electric Blue) personal portfolio, hobby showcase, and live telemetry hub built with **Next.js 15**, **React 19**, **Tailwind CSS**, and **Framer Motion**.

---

## ⚡ Quick Start

```bash
# Run local development server (starts on http://localhost:3000)
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

---

## 🎨 Design System

- **Background**: Pure White (`#FFFFFF` / `#FAFAFA`)
- **Two-Color System**:
  - **Base**: Stark Jet Black (`#09090B` / `#000000`) for typography, hard grid borders, and UI structure.
  - **Accent**: Electric Blueprint Blue (`#0055FF`) for live terminal telemetry, command prompts, highlights, and active states.
- **Nerd-Designer Elements**: Monospace metadata, live IST timezone clock, keyboard shortcuts (`⌘K` command palette), technical architecture breakdowns, and zero visual bloat.

---

## 📂 Easy Content Customization

You can update any content without touching React code:

| File | Content Controlled |
|---|---|
| [`data/profile.json`](./data/profile.json) | Bio, handle, title, live status, metrics, social links |
| [`data/projects.json`](./data/projects.json) | Portfolio projects, architecture notes, benchmarks, code snippets, GitHub links |
| [`data/hobbies.json`](./data/hobbies.json) | Reading list with takeaways & ratings, hardware/dotfiles specs, focus playlists, side obsessions |
| [`data/now.json`](./data/now.json) | Real-time changelog of what you're currently building, learning, and doing |
| [`data/stack.json`](./data/stack.json) | Technical skills matrix & curated Unix terminal commands |
| [`data/experience.json`](./data/experience.json) | Career history, milestones, and education |

---

## ⌘ Keyboard Navigation

- Press `⌘K` or `Ctrl+K` from anywhere on the site to trigger the fast interactive Command Menu.
